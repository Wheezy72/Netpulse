## Global (styles.css)

- **focus-visible** — one rule covers `button, a, select, textarea` plus the
  named `.np-*` controls, so per-view absence of `focus-visible` is not a gap.
  Verified present and specific (2px accent outline, 2px offset).
- **`transition: all` removed (5 sites)** — inputs now transition
  `border-color, box-shadow` only; drawers `transform, opacity`; toasts
  `opacity, transform`; login button `background-color, border-color, color`.
  Nothing animates layout properties any more.
- **prefers-reduced-motion** — 4 global blocks + BrandMark (the animated
  logo) all honour it.
- **No pure #000/#fff surfaces** — remaining `#fff` hits are a mask gradient
  and one terminal foreground, neither a background.
